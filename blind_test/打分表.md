# TTS 引擎盲听打分表

三套引擎已分别用同一段《吐槽成真》台词合成，成品在 `blind_test/blind/A`、`B`、`C` 目录下
（每目录内 `01_system.wav`…`06_linweiwei.wav` 共 6 句）。

**打分顺序**：① 盲听打分 → ② 翻页看结论 → ③ 运行 `reveal` 揭晓引擎。
在打分完成前请不要打开 `blind_test/mapping.key`（里面有答案）。

---

## 一、打分维度（每项 1~5 分）

| 维度 | 说明 |
| --- | --- |
| 音色稳定性 | 同一角色多句之间音色是否统一、不漂移 |
| 中文自然度 | 断句、重音、多音字、口语节奏是否自然 |
| 情绪表现力 | 吐槽/嘲讽/系统音的情绪能否传达到 |
| 机械感（5=最好） | 5=完全不像机器，1=一听就是机器 |

## 二、各角色听点

| 角色 | 重点听什么 |
| --- | --- |
| 林薇薇（年轻女声） | 第 6 句嘲讽是否够「得意/不屑」 |
| 顾琰宸（低沉男声） | 第 4、5 句是否低沉、有压迫感 |
| 旁白·林晓（轻松吐槽） | 第 2、3 句吐槽节奏、语气是否「活」 |
| 系统（电子音） | 第 1 句机械感但清晰、不糊 |
